## S2b POS receipt verification (client site, Odoo 19)
The POS receipt path (RC3) is code-complete and unit-tested on the
native side; these checks need the real Odoo 19 + POS + app:
1. In the browser devtools of the POS inside the app, confirm
   `ReceiptScreen.prototype.printReceipt` is the patched method and the
   receipt element matches `.pos-receipt-container .pos-receipt`.
2. Configure the POS rule (docs/odoo-setup.md) and complete a sale:
   Print Full Receipt prints the receipt as an image on the receipt
   printer; a job row with source `point_of_sale.receipt` appears.
3. Enable Automatic Receipt Printing: the receipt prints on payment
   without a click. Reprint from Orders > Paid > Print Receipt.
4. Open the same POS in a normal browser: default POS printing
   (no bridge -> untouched behaviour).
5. Print a long receipt (30+ lines) and one with the company logo and
   an invoice QR code: check nothing is clipped at 576 dots (80mm).
